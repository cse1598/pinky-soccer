# 범퍼 CAD

파라미터 YAML 하나로 범퍼를 생성합니다. 출력용 STL, URDF용 메시, URDF 파라미터가 함께 만들어집니다. 버전을 추가하려면 YAML을 복사해서 값을 바꾸고 다시 생성합니다.

```bash
cd src/pinky_soccer_description/cad/bumper
source /opt/ros/jazzy/setup.bash && source ~/pinky-soccer/install/setup.bash
python3 generate_bumper.py bumper_v1.yaml
```

필요한 것: Blender 4.2 이상(`blender`가 PATH에 있거나 `--blender <경로>`), `numpy`, `pyyaml`, `trimesh`(MuJoCo 설치 때 함께 설치됨), source된 워크스페이스.

| 생성 파일 | 용도 |
|---|---|
| `print/<name>_print.stl` | **출력용**. mm 단위, 앞면이 바닥을 향함 |
| `print/<name>_report.txt` | 무게, 크기, 지면 간격, 로봇 메시와의 간섭 검사 결과 |
| `../../meshes/visual/<name>.stl` | URDF visual (m, `bumper_link` 좌표계 = 무게중심) |
| `../../meshes/collision/<name>_collision.stl` | URDF collision (앞판 상자만) |
| `../../config/<name>_params.yaml` | `bumper_params_file:=`로 넘기는 URDF 파라미터 (생성 파일, 직접 수정 금지) |

## v1: 기본 평판 + 끼움 돌기

```text
        위에서 본 모습 (왼쪽 절반, base_link mm)

  x 11      20.5                37.5  41.5
   ┌─────────┬────────────────────┬────┐  |y| 33.4   ← 앞쪽 기둥 |y| 34.0
   │  돌기   │      옆벽          │    │
   └─────────┴────────────────────┤ 앞 │  |y| 25.6   ← 초음파 브래킷 |y| 25.0
     두 판 사이   판 앞 가장자리에    │ 판 │
     (35 mm 끼움)  걸림 (미는 힘)    │    │  ... |y| 55 (바퀴 바깥면)
                                   └────┘
```

- **앞판**: IR 기판(x 36.5) 바로 앞(x 37.5~41.5)에 거의 직각으로 세웁니다. 모서리 챔퍼는 0.6mm입니다. 높이는 아래 판 밑면부터 중간 판 윗면까지(지면 9~51mm), 너비는 바퀴 바깥면까지(110mm)입니다.
- **초음파 구멍**: 센서 원통 둘레로 0.5mm 여유를 두고, 원통 앞면부터 반각 25°로 넓어집니다(초음파 빔은 약 15°).
- **돌기 2개**: 아래 판 윗면과 중간 판 아랫면 사이(35mm)에 끼워서 마찰로 고정합니다. 나사는 쓰지 않습니다. 초음파 브래킷과 앞쪽 기둥 사이의 빈 공간(\|y\| 25~34, x 10.5~20.5)으로 들어갑니다.
- **옆벽**: 돌기 앞쪽이 두 판의 앞 가장자리(x 20.5)에 맞닿아서, 공을 미는 힘을 나사가 아닌 판이 받습니다.
- **IR 기판 홈**: 돌기와 옆벽 아래쪽에 IR 기판 가장자리(\|y\| ≤30, 두께 1.6mm)가 지나가는 홈이 있습니다. 홈의 뒤쪽이 열려 있어서 범퍼를 뒤로 밀어 끼우면 됩니다.

### 장착 방법

1. 범퍼를 로봇 정면에 맞춥니다. 돌기 2개가 아래 판과 중간 판 사이의 초음파 모듈 양옆을 향하게 합니다.
2. 수평으로 밀어 넣습니다. 초음파 센서 원통이 구멍으로 들어가고, 옆벽이 판 가장자리에 닿으면 끝입니다.
3. 뺄 때는 앞으로 당깁니다.

### 출력

- 앞면을 베드에 두고 출력합니다(`*_print.stl` 방향 그대로). 서포트가 필요 없습니다. 원뿔 구멍은 베드 쪽으로 넓어집니다(경사 25°).
- 크기는 42 × 110 × 30.5mm, 무게는 약 32g입니다(PLA, 채움 80% 가정).
- **끼움 정도**: `prongs.pinch_interference`(기본 0.1mm)를 35mm 간격에 더합니다. 시험 출력 후 헐거우면 키우고, 안 들어가면 줄입니다. 실물의 판 간격을 먼저 재 보세요.

### 검증

| 항목 | 결과 |
|---|---|
| 메시 닫힘(watertight) | 통과 |
| 공식 visual 메시와의 간섭(공칭 끼움, 0.05mm 초과 침범) | 0 |
| 1mm 이내로 가까운 부품 | 두 판(의도한 접촉), 앞쪽 기둥 0.6mm, IR 기판 0.4~0.5mm, 초음파 원통 0.5mm |
| MuJoCo: 0.25m/s로 공 밀기 | 공을 밀고 감, 최대 pitch 0.04° |
| Gazebo: 0.15 / 1.0m/s로 공 밀기 | 공이 범퍼 앞 62mm에 유지됨, 뚫고 지나가지 않음 |
| 실물 끼움 | **미검증** (출력 후 확인) |

간섭 검사는 공식 **visual** 메시를 기준으로 합니다. 실물과 CAD는 다를 수 있으니 처음에는 시험 출력으로 맞춤을 확인하세요.
