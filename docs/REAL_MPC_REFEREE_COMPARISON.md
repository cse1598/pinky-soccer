## 기준과 실행 조건

- 상부 심판: 흰색 외곽선 중심 규격1.670×1.070m, `referee_field` 좌표계.
- LiDAR: 외곽 벽 내부 폭/길이 기준1.820×1.220m. 흰 선 규격으로 바꾸지 않는다.
- 사용자는 작은 제작 오차 허용과 측정에 근거한 보정값 업데이트를 승인했다.
  원본 보정은 보존하고 변경이 유효한지 비교한 뒤 적용한다.
- 기존 바퀴 반지름/간격·실측τ, 회피OFF, 외부 속도 상한0, 내부 모터/입력 제약 유지.
- 독립 충돌 감시·watchdog·기존 완료 조건 유지.
- 심판 좌표는 먼저 평가에만 사용한다. 기존 World Model/TF/MPC 위치를 덮어쓰지 않는다.

심판은 고정 원을 그리더라도 몸체 영상의 면적 중심을 측정한다. 이 점은 로봇
base_link와 다를 수 있으므로 심판 좌표를 독립적인 base_link Ground Truth로 단정하지 않는다.

## 비교 도구

`scripts/compare_real_mpc_referee.py`는 기존 준비 서비스와 BT GoToPose 요청을 사용한다.
제어기를 새로 구현하거나 속도 명령을 직접 생성하지 않는다.
독립 실행 중인 로봇 bringup·상부 심판이 필요하고, PC 경기 launch는 도구가 관리한다.

순서: `2/align → 0/align → 0/off → 2/off → 2/align 재확인`.
각 단계에서 damping 또는 observer 한 항목만 변경한다. 각 설정의 동일 코스는
시작 위치 준비 후 `(-.50,0,0)` 정렬→`(-.25,0,0)` 전진→`(-.50,0,0)` 후진이다.
공이 시험 구간에 있으면 중단한다. 초기 준비는 기존 팀 시작 위치를 사용한다.

기록은 심판·World Model·MPC·준비/행동 상태의 source/receipt 시간 JSONL이다.
별도 bag에는 cmd/drive/raw joints/odom/IMU/TF도 기록하고 이미지는 포함하지 않았다.
심판 로봇 ID/연속성이 이상하거나 위치가 끊기면 STOP 후 시험 전체를 종료한다.
짧은 검출 누락은150ms까지 평가 데이터에서 제외할 수 있지만, 추정 위치를 MPC에
대체 입력하지 않는다. 제어 노드는 원래 센서 보호를 별도로 수행한다.

2/align 두 시험의 25cm 전진·후진 결과(종료 당시 심판 위치, 좌표 정렬 없음):

시간은 요청부터 종료 후 0.5초 정지 관측까지 포함한다. 별도 분석의 마지막 0.2초
평균 위치 오차는 1차 4.4/23.1mm, 재확인 2.8/10.2mm였다. 심판은 기존 KF를 거친

심판·차량 위치의 이동량 차이는 1차 약20mm, 재확인 약22~25mm로 남았다.

재확인 2/align의 drive 최대 속도는 약0.269m/s, odom 최대 속도는 전진0.283m/s,
후진0.270m/s였다. 외부 상한 없이 기존 내부 제약으로 동작했다.
해당 전진·후진에서 시작/끝 정지를 제외한 80ms 이상 exact-zero drive 구간은 없었다.
그러나 |v|>0.01m/s 기준 명령 부호 전환은 전진3회/후진1회로, 도착부 보정이 남았다.
`0/align` 전진은5회, `0/off` 실패 전진은11회였다. 이 부호 전환은 회전/모든 바퀴의
진동과 동일한 지표가 아니며, 성공만으로 완전히 부드러운 이동이라고 보고하지 않는다.
0/off의 단일 누락은 실패한 전진 구간에서 발생했다(had_offer=false).
도착부 반전과 누락이 함께 관측됐지만, 단일 누락이 4초 진전 없음 실패를 직접
유발했는지는 확인되지 않았다. 원시 시간축을 보존하고 별도 원인으로 단정하지 않는다.

첫 2/align 시험의 cmd/drive/odom bag은 정렬·전진을 놓치고 후진 중간부터 수집됐다.
첫 시험의 zero 구간/최대 속도는 비교에서 제외한다. JSONL의 MPC 상태 및 심판 위치는
